# Population correlation between two variables

Population correlation between two variables

## Usage

``` r
RHO(x, y)
```

## Arguments

- x:

  A bare variable name.

- y:

  A bare variable name.

## Value

A `RHO` / `param_obj` S7 object.

## Examples

``` r
RHO(speed, dist)
#> <param: RHO>
#> 
#> -  x => speed
#> -  y => dist
#> 
```
