# Tidy a concluded statistical result

Tidy a concluded statistical result

## Usage

``` r
tidy(.x, ...)
```

## Arguments

- .x:

  A `cld_exec` object produced by
  [`conclude()`](https://joshuamarie.github.io/statim/reference/conclude.md).

- ...:

  Passed to the registered tidy function.

## Value

A tibble.
